# CRUD Buku Perpustakaan (PHP + MySQL)

Fitur: Tambah, Tampil, **Edit**, dan **Hapus** data buku.

## Cara menjalankan
1. Install XAMPP, jalankan Apache dan MySQL.
2. Import `database.sql` lewat phpMyAdmin.
3. Salin folder ini ke `htdocs/` lalu buka `http://localhost/crud-buku/dashboard.php`.

## File
- `dashboard.php` : tampilan form dan tabel
- `proses.php`    : logika insert, update, delete
- `koneksi.php`   : koneksi database
- `database.sql`  : struktur tabel
